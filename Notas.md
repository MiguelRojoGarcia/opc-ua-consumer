2. Azure IOT Hub

Servicio de Azure que permite la comunicación bidireccional entre dispositivos y aplicaciones en la nube.

3. Azure IoT Edge

Dispositivo de Azure que permite la ejecución de aplicaciones en dispositivos IoT. Se suele utilizar para ejecutar aplicaciones de procesamiento de datos en dispositivos IoT.
y posteriormente enviar los datos a la nube.
